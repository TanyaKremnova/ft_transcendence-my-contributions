# ft_transcendence | Codamium — My Contributions

This repository contains my individual contributions to the ft_transcendence full-stack publishing platform (team project at Codam).

The full project is a collaborative 4-person team effort. This repo showcases 
the specific features I developed.

## My Features

### 1. Friends System
- **Frontend:** React component for friend requests, accept/reject/cancel
- **Frontend:** Friend list display with online status indicators
- **Backend:** Friend relationship database models and API endpoints
- **Backend:** Real-time online/offline status using WebSockets

**Tech:** React, TypeScript, Node.js/Express, PostgreSQL, WebSockets

### 2. Follow System
- **Frontend:** Follow/unfollow buttons and follower/following counts
- **Frontend:** User profile showing follow relationships
- **Backend:** Follow relationship models and API
- **Backend:** Cascade updates for follower/following counts

**Tech:** React, TypeScript, Express, PostgreSQL

### 3. Direct Messaging with WebSockets
- **Frontend:** Chat interface with message history and real-time delivery
- **Frontend:** User selection and conversation list
- **Backend:** WebSocket server for real-time messaging
- **Backend:** Message persistence in PostgreSQL
- **Backend:** Chat history retrieval API

**Tech:** React, TypeScript, WebSockets, Node.js/Express, PostgreSQL

### 4. Notification System
- **Frontend:** Notification center displaying all events
- **Frontend:** Mark as read, mark all as read functionality
- **Frontend:** Unread count indicators
- **Backend:** Event-driven notification creation (follows, comments, likes, etc.)
- **Backend:** Notification state management (read/unread)

**Tech:** React, TypeScript, Express, PostgreSQL, Event-driven architecture

## Technology Stack

**Frontend:** React, TypeScript, CSS/styling  
**Backend:** Node.js, Express.js  
**Database:** PostgreSQL, Prisma ORM  
**Real-time:** WebSockets  
**Version Control:** Git, pull requests, code reviews  

## Project Context

ft_transcendence is a full-stack collaborative project developed by a team of 4 students at Codam Coding College. The team divided work by features, with each developer responsible for both frontend and backend of their assigned features.

This approach gave me end-to-end ownership of my features and experience with 
the full development lifecycle.
